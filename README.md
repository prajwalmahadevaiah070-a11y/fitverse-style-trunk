# FitVerse Style Studio

Build FitVerse, a production-ready mobile-first PWA universal fashion marketplace and doorstep home try-on ecosystem. Implement the requested luxury dark slate / stone white / champagne-gold visual system, responsive bottom navigation, gender/category hierarchy and filters, a mock but interactive Digital Try-On Studio (photo/camera upload, mannequin choices, garment layers with transform controls, comparison and WhatsApp sharing), Trial Trunk with a four-item cap and booking/payment mock flow, plus Retailer Portal with local product upload, active trial queue, and earnings. Use React, Tailwind CSS, TypeScript, and Lucide icons. Seed 18 realistic Indian fashion catalog products and make cart, photos, and seller-added products persist through local storage.
